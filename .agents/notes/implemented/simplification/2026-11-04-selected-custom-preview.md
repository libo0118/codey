# Agent Note: 预览分支仅保留选定的 custom 能力

Status: implemented

## Problem

CodeyX 集成分支从 custom 创建，隐含包含全部 fork 定制。用户只选思考档位同步、直连统计、Linux 与 fork 更新发布，并明确要求速度使用上游、撤掉未改善现场问题的子代理生命周期和会话选择补丁。

## Decision

- 在现有集成分支逐块撤销 `5364c29f..22247b99` 中速度、生命周期、会话选择独有差异，保留上游同类基础实现以及后续 CodeyX 功能、自定义角色、备份与远程链路。custom、既有正式标签和用户安装均不修改。
- 速度完整使用上游的客户端行为，不保留 fork 的 Ultrafast 原生资格收紧；上游客户端声明不代表服务端接受或实际加速。
- 去掉 fork 的失败派发恢复、额外终态身份保留、会话选择刷新与 observer 过滤，不新造替代机制，也不整文件覆盖后续动态角色和手机桥接代码。上游原有权限、审批、输入验证和显式删除确认保留。
- 旧账本字段只按上游兼容规则读取，不在真实用户目录执行清理或迁移。验证旧字段读取、当前派发与远程桥接契约，不把测试通过当作现场问题已解决。

当前重叠兼容实现采用[上游优先边界](../bug-fix/2026-11-04-upstream-151-compatibility.md)，本篇的 custom 取舍不变。

[失败派发回执恢复](../bug-fix/2026-11-06-failed-spawn-recovery.md)仅部分取代本篇的失败派发范围；[上游 v1.5.2 整合](../bug-fix/2026-11-06-upstream-152-integration.md)沿用该边界，其余旧 fork 生命周期裁剪决定不变。

## Alternatives considered

- 继续保留未选修复：可保留已知终态及跨会话保护，但用户明确表示使用后仍有问题并要求不用；不以底层修复名义继续纳入。
- 直接恢复整份上游文件：最省操作，但会覆盖思考档位、直连统计、Linux 或后续 CodeyX 自定义角色和手机桥接；只回退有归属的差异。
- 从 CodeyX 参考仓重建：基线更接近参考项目，但无共同祖先，需要重新适配大量已完成集成；保留当前分支并审查逐块裁剪。

## Consequences

- 选定的四组能力、CodeyX 集成和自定义子代理保持原接线；未选差异及其专用测试和无效引用清理，速度与会话选择部分对照上游，手机桥接相对裁剪前保持不变。
- 本地验证入口为 TypeScript、全量 Node、Rust 格式和元数据；Windows/Linux CI 执行 Rust 测试、Clippy 和打包，成功后才发布独立预览版，不标记 Latest。独立静态复核不替代这些执行结果。
- 活动笔记按速度、生命周期和会话选择检索：部分取代[原合并选择边界](../bug-fix/2026-11-03-upstream-selection-boundary.md)的保留决定，其思考档位、遥测与 Linux 理由仍有效；[自定义角色](../feature/2026-11-04-custom-subagents.md)、[远程及数据](../architecture/2026-11-03-codeyx-remote-and-data.md)和[内置工具](../feature/2026-11-03-codeyx-managed-tools.md)继续生效，不改写旧决定为相反结论。
- 撤回补丁恢复上游对应行为，可能恢复已知的延迟事件或跨会话选择边界问题，不承诺解决用户原问题。预览版需备份后实机验证，重要删除操作应核对目标会话。
- 现有磁盘账本和真实 Codex 的跨版本行为尚未实测；本机无链接器，原生验证依赖 CI。不能把源码、Mock 或 CLI 顶层参数解析当成真实派生及手机链路证明。
