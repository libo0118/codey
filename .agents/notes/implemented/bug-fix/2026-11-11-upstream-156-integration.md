# Agent Note: 同步上游 1.5.6 并保留集成分支边界

Status: implemented

## Problem

集成分支基于上游 1.5.2；正式版 1.5.6 增加会话识别、协作终态、静态资源和用量界面的兼容及性能改进。重叠代码同时承担本分支自定义角色、原生只读证明、失败派发恢复和直连计时，不能用整份上游文件覆盖。

## Decision

- 合并正式标签 `v1.5.6` 指向的 `bbe11607dc601c32d8d2dbdaf49e73725dd07f45`，不混入其后尚未发布的 master 提交。源码候选版本为 `1.5.6-libo.1-preview.1`；同步不创建发布标签、不发布、不安装，也不修改 custom 分支。
- 保留自定义角色注册、显式删除、1..64 并发和失败派发恢复。上游 `6f558fd6` 把内置角色统一为可写，只读职责改由提示词引导；该权限放宽不带入本分支。继续保留 Explorer 当前轮的原生只读证明、未知工具与包装器限制、Reviewer 源码写入限制。上游新的受验证 transcript 定位和协作终态解析仍采用。
- 统计采用 1.5.6 的总量展示与新浮层交互，保留原生直连计时及路由／原生来源隔离。普通路由的 TTFT 边界说明移到字段提示，原生计时仍明确标出来源；不靠旧文案测试阻止上游界面演进，也不把缺失计时补成有效数据。注入版本更新以替换已加载的旧实现。
- 删除上游已移除且不再依赖的 Runtime 数据层，保持剩余 workspace、依赖和锁文件一致；远程认证、附件、近期优先加载、WebDAV、受管工具和 fork 的 Windows/Linux 公开构建流程不裁剪。

## Existing-note audit

[1.5.2 合并](2026-11-06-upstream-152-integration.md)保留旧基线和权限取舍，本记录承接后续正式版；[自定义角色](../feature/2026-11-04-custom-subagents.md)、[可配并发](../feature/2026-11-04-subagent-concurrency.md)、[失败派发恢复](2026-11-06-failed-spawn-recovery.md)仍分别约束其运行时行为。[已选 custom 范围](../simplification/2026-11-04-selected-custom-preview.md)不因同步扩大；远程投影和工具安装记录无决定冲突，不重写或归档。

## Alternatives considered

- 直接跟随 master 可拿到发布后的修复，但这不是已发布的最新版本，扩大了验证范围；本次使用正式标签。
- 完整采用上游权限简化可减少维护差异，但会放宽已有只读角色的工具及原生权限；保留原边界，仅合入兼容和生命周期识别改进。
- 固守旧统计界面和测试文案可减少冲突，但会丢失上游交互与总量展示；保持真实数据口径与来源约束，按新界面验证展示位置。

## Verification

JavaScript 全量回归、TypeScript 检查、前端生产构建、Rust 格式及 Cargo 锁文件解析在本机执行；Windows 本机缺少 MSVC 链接器，Rust 编译、全量测试与 lint 交给现有 CI 工作流，不把源码检查当作编译完成。真实 Codex 运行、权限切换与远程客户端仍需另行现场验证。

## Consequences

自定义角色权限与原生计时继续需要维护小范围 fork 差异；已有旧统计版本重新加载后会切换到新实现。CI 的手动分支构建仅上传产物，不触发 tag 发布，不自动替换任何用户正在运行的程序。
