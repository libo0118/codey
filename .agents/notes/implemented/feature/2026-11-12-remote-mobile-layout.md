# Agent Note: 远程移动页面视觉与鸿蒙宿主边界

Status: implemented

列表与新建页的纯 Web/旧 DOM 保留决定由 [Cindy 页面切片与 DOM v2](../architecture/2026-11-13-cindy-page-slices-and-dom-v2.md)部分取代；本篇的消息、输入、审批与阅读锚点边界仍有效。

## Problem

用户确认 Cindy 轻量内容层与已有鸿蒙外壳结合的移动样式。原输入区将附件、权限、模型和任务操作挤在一起；仅替换颜色不足以呈现已确认的层级。鸿蒙壳还依赖远程页面的公开 DOM，不能为换皮破坏菜单接管或重新实现认证和任务协议。

## Decision

- 消息、登录、审批与只读控制台保留 React 网页及现有传输、控制器，以暖白/近黑、细描边与清晰排版呈现。移动端保留单页切换，桌面保留双栏；列表与新建页的依赖和结构以新笔记为准。
- 搜索首屏可见但不自动聚焦，避免进入列表就唤起手机键盘。列表、新建与会话导航按显式 DOM v2 标记提供给新版 HAP，旧标题/电脑状态的固定层级不再是本分支合同。
- 附件、正文和发送/停止位于同一输入行；权限和可读模型名称位于其上方。既有模型弹层与高级面板继续使用原设置动作，高级面板也可操作同一权限字段；“完成”只关闭面板，不伪装成新的延迟提交协议。未知结果防重、附件丢失禁发、断线只读、已有任务停止/补充语义不变。
- 审批仍只显示可核对的公开详情，显式点击才响应；次要决定在前，本次允许在最后，视觉与键盘顺序一致。不增加盲批或自动重试。
- 连续活动保留原顺序与现有原生 details，折叠时只显示最新公开动作标题；命令只预览首行，工具只用合同中的名称，不从任意 text、输入或输出猜测步骤。展开外层才创建步骤，展开步骤才创建结果，关闭后卸载正文，不自动改变用户的展开选择。
- 点击过程或步骤标题、加载历史会暂停尾随并记住原阅读锚点。原生 details 收缩造成的被动滚动不能恢复尾随；主动滚回底部、点击最新消息、成功发送或切换会话才恢复。复用现有滚动容器，不移植 Cindy 的 React Native 虚拟历史框架。
- 网页不重复添加原生底栏、主机存储或扫码协议。用户后续明确要求 HAP 隐藏独立 Chat，但不删除其数据；HAP 的三个入口及 Magpie 导航适配由独立手机仓库负责，不扩展本仓远程 API。

## Existing-note audit

[远程消息与深链](2026-11-04-remote-rich-timeline-and-links.md)继续约束详情懒创建、消息顺序、文件与剪贴板；[运行状态指示](2026-11-04-remote-running-indicators.md)继续约束真实运行状态；[远程数据边界](../architecture/2026-11-03-codeyx-remote-and-data.md)继续约束认证和只读控制台。三者均部分重叠、保持有效，不重写或归档，无需删除旧提案。

## Alternatives considered

- 迁移 Cindy 的 Expo/React Native 页面可以接近其原生动效，但会为视觉改造引入另一套运行时、宿主和业务接线；保留现有网页技术栈。
- 只替换 CSS 改动最少，但不能把输入主操作和模型/权限层级分开；仅调整必要的现有组件结构和原回调，不重写控制器。
- 直接在每个 scroll 事件按底部距离恢复尾随无需额外状态，但详情收缩也会产生 scroll，导致刚手动查看就被后续增量带走；区分查看暂停与主动滚动，不增加协议或历史存储。

## Verification

- 子组件、公开消息、输入附件、控制器、无效连接及宿主头尾合同的定向 Node 回归 78 项通过；新增高级权限接线/关闭和首屏不聚焦断言。
- 实际生产远程 bundle 的隔离浏览器夹具覆盖列表、聊天、模型权限、审批、登录及只读控制台；设置、发送、停止和审批只记录合成请求。审批点击前无写操作，点击后仅一次 respond。
- 实际 HAP CodeyUi 脚本与生产 bundle 同时运行，确认支持识别、列表/聊天布尔状态及原底部动作接管；390px 无横向溢出。320×500 测试视口下输入区仍在视口内；不将缩小浏览器视口称为真实软键盘验收。
- 新增过程标题和查看暂停回归，含折叠收缩反例、工具输入/输出及思考正文不提前挂载；消息/活动/流/附件/审批/列表六文件 43 项检查通过，类型及远程生产构建通过。390px 真实 bundle 验证两级按需挂载／关闭卸载、查看时出现最新消息按钮、主动滚到底部恢复；320×500 无横向溢出，输入区底部约460px。

## Consequences

界面更接近已确认样式，但不新增生产能力；HAP 仍需独立编译和真机验证。只读控制台不提供账号配置、安装或重启。所有截图只用合成数据，不连接生产网关或模型。本机样式检查不替代上游新版本整合、平台构建与真实服务验证；本次不自动发布或部署。
