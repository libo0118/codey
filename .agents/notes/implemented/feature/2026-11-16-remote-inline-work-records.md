# Agent Note: 原位工作记录

Status: implemented

## Problem

工具、回答和子代理事件已有安全的公开投影，但所有连续活动共用折叠入口，单次工具和子代理事件也被藏入过程。用户选择按桌面截图展示原位灰色记录，不采用将历史过程集中到正文之后的样式。

## Decision

- 单次工具及子代理生命周期／协作事件独立成行，按原数组顺序穿插正文；连续普通活动保留默认折叠的过程入口，展开使用细线列表，正在执行的末组显示“正在思考”。
- 工具、命令及子代理结果继续逐项展开才建立正文，关闭即卸载；沿用原生 details、消息 identity、公开名称和现有字段，不从任意输入／输出猜测标题，不为外观扩大 wire。
- 单次工具与后续连续过程共用同一分组组件和消息 key，增加第二步不重建第一步的详情；外层展开态随用户选择保留，单次记录的分组标题隐藏，真实工具行仍可独立展开。
- 复用现有主题变量与图标，保留键盘焦点、移动触控热区、查看过程暂停尾随及历史只追加对话的规则。

## 活动笔记审计

- [富时间线](../../implemented/feature/2026-11-04-remote-rich-timeline-and-links.md)与[移动层级](../../implemented/feature/2026-11-12-remote-mobile-layout.md)部分重叠：仅细化哪些活动独立成行及摘要视觉，公开投影、惰性详情和阅读暂停边界不变。
- [有界公开流](../../implemented/architecture/2026-11-04-bounded-remote-stream.md)及[对话历史分页](../../implemented/bug-fix/2026-11-14-remote-dialogue-history.md)互补；不恢复历史过程，不删除原生记录。
- 其余活跃笔记没有对应提案需要归档或拒绝。

## Alternatives considered

- 所有过程保持单一折叠入口可以减少节点，但会隐藏截图中需要直接看见的单次工具及子代理事件。
- 将所有过程默认展开更接近静态截图，但工具密集时会放大 DOM 和结果渲染成本；只让独立记录露出摘要，连续过程和详情仍按需展开。
- 增加 server／displayTitle 或解析任意 arguments 可以补充部分标题，但当前字段不能保证还原桌面所有文案；此次只改变已公开数据的呈现，不猜测缺失记录。

## Verification

- 新记录分类回归先红，生产消息／协作／历史流／富文本四文件42项通过；类型检查、生产构建通过。全量 Node 首轮唯一失败来自缺少 `cargo` PATH，临时加入现有便携工具链后对应 Python 脚手架用例单独通过，未修改无关源码或测试约定。
- 生产 bundle 使用隔离合成传输，1180px桌面、390px浅色和320px深色没有横向溢出，手机记录点击区至少44px；未知结构、附件与公开结果继续沿用原实现。
- 浏览器中打开单次命令后追加第二步，命令 details 的 DOM nodeId 前后均为28，保持展开并接收追加输出；键盘收起外层后步骤与结果均卸载。查看时暂停尾随，无目标栏不占位。

## Consequences

单次工具与子代理事件直接可见，连续密集过程仍保持惰性渲染；与原界面相比增加少量记录摘要节点，移除折叠入口下方重复的最新动作预览。这是已公开近期／实时记录的样式改造，不等同于复原未投影或已截断的 Native 数据；没有原生业务代码变更；原生打包、部署及真机验收另行执行，合成样式验证不代表真实任务或手机已验收。
